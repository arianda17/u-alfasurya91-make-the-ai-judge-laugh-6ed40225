# Make the AI Judge Laugh

This is my entry for the make.fun bounty "Make the AI Judge Laugh" (slug: `u-alfasurya91-make-the-ai-judge-laugh-6ed40225`).

## The Joke

The office printer only ever jams when there's a deadline — clearly it has better time management than I do.

*Observation: printers fail at the worst moment; the twist reframes that as the printer having superior (if adversarial) time management.*

## How to Run

```bash
node main.ts
```

The program writes the joke to `/output/entry.txt` and prints it to stdout.

*The entry targets the judge's criteria: a true office observation (printer jams on deadline) followed by a surprising turn (the printer has better time management), delivered in one tight line.*
